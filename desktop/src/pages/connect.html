Connect agents

Connecting an AI tool lets it take tasks in your workspace, ask you questions and report back there. It works through the quadit command and its skill, through Quadit's MCP server, or both; you see every file that changes before anything is written, and Disconnect takes it back.

Connecting agent tools is not available on Windows yet: it needs the quadit command, which has no Windows build. You can still add Quadit's MCP server to a tool by hand: its address is your server's address followed by /mcp.
